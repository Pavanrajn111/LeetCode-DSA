# 509. Fibonacci Number

**Difficulty:** Easy
**LeetCode:** https://leetcode.com/problems/fibonacci-number/
**Language:** Java

## Problem

Compute the n-th Fibonacci number.

## Approach

Iterative bottom-up computation that only keeps the previous two values instead of building a full array.

## Complexity

- **Time:** O(n)
- **Space:** O(1)
