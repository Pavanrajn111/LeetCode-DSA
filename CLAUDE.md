# Commit message convention
Every time a LeetCode problem is solved, commit with a message in one of these formats:
- "Solved <Problem Name> using <technique>"   e.g. "Solved Two Sum using hash map"
- "Solved <Problem Name> correctly"            when there is no clear technique
- "Added README for <Problem Name>"            for README-only commits
- "Solved <Problem A> and <Problem B>"         for multiple problems in one commit
Rules: past tense, capital first letter, max 72 characters, no trailing period.
One problem per commit where possible. Always use the official LeetCode problem title.
Before committing, check which files changed and pick the problem name and technique from them.
