# 9. Palindrome Number

**Difficulty:** Easy
**LeetCode:** https://leetcode.com/problems/palindrome-number/
**Language:** Java

## Problem

Determine whether an integer reads the same forwards and backwards, without converting it to a string.

## Approach

Reverse the digits of the number into a new value, then compare the reversed value against the original.

## Complexity

- **Time:** O(log n)
- **Space:** O(1)
